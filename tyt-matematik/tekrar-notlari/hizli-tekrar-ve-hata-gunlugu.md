# Hızlı tekrar ve hata günlüğü

## Soru öncesi 20 saniyelik kontrol

1. İstenen nicelik ne ve birimi nedir?
2. Değişken hangi kümede: gerçek, tam, doğal, rakam, kişi sayısı?
3. Verilenler arasında sabit kalan toplam, oran, iş, yol veya saf madde var mı?
4. En kısa uygun temsil hangisi: denklem, tablo, sayı doğrusu, Venn, grafik, şekil?
5. Kullanacağım kuralın koşulu sağlanıyor mu?

## Soru sonrası kontrol

- Sonucu özgün koşula geri koy.
- İşaret ve büyüklüğü tahminle karşılaştır.
- Birim doğru mu?
- Tam sayı/pozitiflik/kapasite gibi bağlam koşulu sağlanıyor mu?
- Seçenek varsa yanlış seçenek hangi tip hatadan doğuyor?

## Konu aileleri için ana refleks

| Aile | İlk refleks |
|---|---|
| Sayılar | Evreni ve bütün sayı koşullarını yaz |
| Bölünebilme | $a=bq+r$, $0\le r<b$ |
| Eşitsizlik | Negatif çarpan/bölende yönü kontrol et |
| Mutlak değer | Merkez ve uzaklık olarak oku |
| Üslü-köklü | Ortak taban veya tam kare çarpan ara |
| Çarpan-denklem | Tanım koşulu → çarpan → aday → özgün denklem kontrolü |
| Oran-problem | Birim → tablo → değişmez ilişki |
| Kümeler-mantık | Evren → ortak bölge → niceleyici |
| Fonksiyon | Tanım kümesi → girdi sırası → çıktı kontrolü |
| Sayma-olasılık | Sıra → tekrar → yasak → örnek uzay |
| Veri | Başlık → eksen → birim → bütün |
| Geometri | Verilen işaret → kesin ilişki → yardımcı çizginin amacı |
