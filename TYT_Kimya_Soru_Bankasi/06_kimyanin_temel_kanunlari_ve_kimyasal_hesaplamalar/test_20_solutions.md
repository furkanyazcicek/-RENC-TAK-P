## Soru 1 (ID: KIM-TYT-K06-T20-S01)
- **Doğru Seçenek:** C
- **Kazanım:** Avogadro sayısını mol birimine çevirerek kapalı formül analiziyle kütle hesaplar.
- **Zorluk Seviyesi:** Orta
- **Çözüm:** $3.01 \times 10^{23}$ tane = $0.5 \ mol$. (Sadece C atomları 0.5 molmüş).
$CH_3COOH$ molekülünde toplam 2 tane Karbon (C) var.
Bileşiğin molü 'n' olsun. İçindeki C molü = $2n$.
$2n = 0.5 \Rightarrow n = 0.25 \ mol$ (Bileşiğin kendi molü).
Bileşiğin MA'sı ($C_2H_4O_2$); $(2 \times 12) + (4 \times 1) + (2 \times 16) = 24 + 4 + 32 = 60 \ g/mol$.
Kütle = $0.25 \times 60 = 15 \ gram$. (C).

## Soru 2 (ID: KIM-TYT-K06-T20-S02)

## Soru 3 (ID: KIM-TYT-K06-T20-S03)
- **Doğru Seçenek:** B
- **Kazanım:** Gaz karışımı problemlerinde iki bilinmeyenli denklemle kütle hesaplar.
- **Zorluk Seviyesi:** Zor
- **Çözüm:** $C_2H_4$ ($MA=28$) 'e $x \ mol$, $C_3H_8$ ($MA=44$) 'e $y \ mol$ diyelim.
Kütle denklemi: $28x + 44y = 100 \ gram$.
Yanma (Çıkan $CO_2$):
$C_2H_4$'ten $2x \ CO_2$ çıkar.
$C_3H_8$'den $3y \ CO_2$ çıkar.
Toplam $CO_2$ = $2x + 3y$.
Soruda $308 \ gram \ CO_2$ demiş. Molü = $308 / 44 = 7 \ mol$.
Denklemler:
1) $28x + 44y = 100$ (Sadeleştir: 4'e böl $\Rightarrow 7x + 11y = 25$)
2) $2x + 3y = 7$ (Çıkan CO2)
İkinciyi -3.5 ile çarpıp birinciyle toplayabiliriz veya x, y tam sayı mıdır diye deneriz.
$y = 1$ olsa, $2x + 3 = 7 \Rightarrow 2x = 4 \Rightarrow x = 2$.
Üstteki denkleme koyalım: $7(2) + 11(1) = 14 + 11 = 25$. Sağladı!
Demek ki $x = 2 \ mol$ ($C_2H_4$), $y = 1 \ mol$ ($C_3H_8$).
Bize $C_2H_4$ kütlesini soruyor. $2 \ mol \times 28 = 56 \ gram$. (B).

## Soru 6 (ID: KIM-TYT-K06-T20-S06)
- **Doğru Seçenek:** B
- **Kazanım:** Katlı Oranlar yardımıyla iki bileşik arasındaki bilinmeyen formülü çıkarır.
- **Zorluk Seviyesi:** Zor
- **Çözüm:** I. Bileşik: %40 X, %60 Y. Formül: $X_1Y_3$.
X'in bir kütle payı = $40 / 1 = 40$ birim.
Y'nin bir kütle payı = $60 / 3 = 20$ birim. (Yani X, Y'nin 2 katı ağır).
II. Bileşik: %50 X, %50 Y. (Eşit kütle).
Madem X'in atom kütlesi Y'nin 2 katı (40'a 20), eşit kütlede olmaları için formülde Y'den 2 KAT daha fazla TANE olmalıdır.
Yani Formül $XY_2$ olmalıdır. (X'ten 1 tane=40g, Y'den 2 tane=40g, Eşitlendi!). (B).

## Soru 7 (ID: KIM-TYT-K06-T20-S07)
- **Doğru Seçenek:** C
- **Kazanım:** Hacimden mol, oradan da kütlenin korunumuna (veya gazların toplam kütlesine) geçer.
- **Zorluk Seviyesi:** Zor
- **Çözüm:** Oda koşullarında 1 mol gaz 24.5 Litredir.
Karışım (Girenlerin toplamı) = 24.5 Litre = $1 \ mol$ Gaz.
Tepkime: $2 N_2 + 5 O_2 \rightarrow 2 N_2O_5$.
Toplam giren $2+5=7 \ kat$.
1 mol gazı bu katlara bölersek:
$N_2 = 2/7 \ mol$. $O_2 = 5/7 \ mol$.
Kütle hesapla:
$N_2$ Kütlesi = $(2/7) \times 28 = 8 \ gram$.
$O_2$ Kütlesi = $(5/7) \times 32 = 160 / 7 = 22.85 \ gram$.
Toplam Kütle = $8 + 22.85 = 30.85 \ gram$. (C).

## Soru 8 (ID: KIM-TYT-K06-T20-S08)
- **Doğru Seçenek:** B
- **Kazanım:** Sabit hacimli kapta gaz haldeki tepkimenin, mol sayısına bağlı kısmi basınç oranını hesaplar.
- **Zorluk Seviyesi:** Zor
- **Çözüm:** Tepkime: $C_2H_4 + 3O_2 \rightarrow 2CO_2 + 2H_2O (sıvı)$
Başlangıç (P1): 0.2 mol $C_2H_4$ + 0.8 mol $O_2$ = Toplam $1.0 \ mol$ gaz. ($P_1 \propto 1.0$).
Harcanan: 0.2 mol $C_2H_4$ (Biter).
$O_2$ harcanan = $0.2 \times 3 = 0.6 \ mol$. Artan $O_2 = 0.8 - 0.6 = 0.2 \ mol$.
Oluşan gaz: $0.2 \times 2 = 0.4 \ mol \ CO_2$ gazı.
$H_2O$ SIVI olduğu için gaza katılmaz!
Son gaz toplamı (P2) = Artan $O_2$ (0.2) + Oluşan $CO_2$ (0.4) = $0.6 \ mol$ gaz.
$P_1 / P_2 = 1.0 / 0.6 = 10 / 6 = 5/3$. (B).

## Soru 9 (ID: KIM-TYT-K06-T20-S09)

## Soru 10 (ID: KIM-TYT-K06-T20-S10)
- **Doğru Seçenek:** C
- **Kazanım:** Yanma deneyindeki kütle artışından verim yüzdesi bulur.
- **Zorluk Seviyesi:** Orta/Zor
- **Çözüm:** Mg kütlesi 20g idi, 30g oldu. Demek ki 10 gram Oksijen (O) bağlandı.
Eğer %100 yansaydı ne olurdu?
Denklem: 24 gram Mg yandığında 16 gram Oksijen bağlar.
20 gram Mg yandığında X gram bağlar.
$X = (20 \times 16) / 24 = 320 / 24 = 13.33 \ gram$ Oksijen bağlaması gerekirdi.
Fakat gerçekte 10 gram bağlamış.
Verim = $(10 / 13.33) \times 100 = 10 / (40/3) = 30/40 = 3/4 = \%75$. (C).
