# Test 19 - Çözümler

## Soru 1 (ID: KIM-TYT-K06-T19-S01)
- **Doğru Seçenek:** B
- **Kazanım:** Farklı gazların içerdiği eşit oksijen mollerinden kütle geçişi yapar.
- **Zorluk Seviyesi:** Orta/Zor
- **Çözüm:** $0.4 \ mol \ SO_3$'teki oksijen molü = $0.4 \times 3 = 1.2 \ mol \ O$.
$N_2O_5$ gazının kendi molü $n$ olsun.
İçindeki oksijen = $n \times 5 = 5n$.
Soru "aynı oksijen içeriyor" diyor. Yani $5n = 1.2 \Rightarrow n = 1.2 / 5 = 0.24 \ mol$ $N_2O_5$.
$N_2O_5$ Kütlesi = $0.24 \times MA$.
MA ($N_2O_5$) = $(2 \times 14) + (5 \times 16) = 28 + 80 = 108 \ g/mol$.
$0.24 \times 108 = 25.92 \ gram$. (B).

## Soru 2 (ID: KIM-TYT-K06-T19-S02)
- **Doğru Seçenek:** B
- **Kazanım:** Sabit basınçlı (pistonlu) sistemde özkütle-hacim (mol) ilişkisini yüzde değişimiyle çözer.
- **Zorluk Seviyesi:** Zor
- **Çözüm:** Kütle (m) sabittir. $d = m / V$.
Başlangıç molü = 5V hacim kaplasın.
Bitiş molü = 3V hacim kaplar.
Başlangıç Özkütlesi ($d_1$) = $m / 5$.
Bitiş Özkütlesi ($d_2$) = $m / 3$.
Artış miktarı: $m/3 - m/5 = 2m/15$.
Yüzde Artış = (Artış / İlk Değer) $\times 100$
$(2m/15) / (m/5) = (2/15) \times (5/1) = 10/15 = 2/3$.
Yüzde olarak: $2/3 = \%66.6...$ (Yani %66.6 artar). (B).

## Soru 3 (ID: KIM-TYT-K06-T19-S03)
- **Doğru Seçenek:** B
- **Kazanım:** Eşit kütle kurgusunda reaktiflerin gerçek MA'larından hareketle artan maddeyi bulur.
- **Zorluk Seviyesi:** Orta
- **Çözüm:** $CaS$ MA'sı = $40 + 32 = 72 \ g/mol$.
Oluşan 36 gram CaS olduğuna göre, (72'nin tam yarısı) demek ki 0.5 moldür.
1 mol CaS oluşurken $\rightarrow$ 40g Ca ve 32g S gerekir.
0.5 mol oluşurken $\rightarrow$ 20g Ca ve 16g S harcanır. (Harcananlar bunlardır).
Soru "Eşit kütlede alındı" diyor. Harcananlardan BÜYÜK olanına göre alınmıştır. İkisinden de 20'şer gram alınmıştır.
Ca = 20g alındı, 20g harcandı (Bitti).
S = 20g alındı, 16g harcandı, $20 - 16 = 4 \ gram$ S (Kükürt) ARTTI. (B).

## Soru 4 (ID: KIM-TYT-K06-T19-S04)
- **Doğru Seçenek:** D
- **Kazanım:** Yanma denklemi üzerinden oksijeni bulup havaya geçer.
- **Zorluk Seviyesi:** Orta
- **Çözüm:** 8.96 L = 0.4 mol $C_3H_4$.
Yanma: $C_3H_4 + 4 O_2 \rightarrow 3 CO_2 + 2 H_2O$.
$1 \ mol$ için $4 \ mol \ O_2$ lazım.
$0.4 \ mol$ için $0.4 \times 4 = 1.6 \ mol \ O_2$ lazım.
1.6 mol $O_2$ hacmi = $1.6 \times 22.4 = 35.84 \ Litre \ O_2$ gereklidir.
Havanın %20'si (Yani 5'te 1'i) oksijendir.
Gereken Hava = $35.84 \times 5 = 179.2 \ Litre$ Hava. (D).

## Soru 5 (ID: KIM-TYT-K06-T19-S05)

## Soru 6 (ID: KIM-TYT-K06-T19-S06)
- **Doğru Seçenek:** C
- **Kazanım:** Tanecik sayısından kütleye, kütleden başka bir gazın mol ve hacmine geçer.
- **Zorluk Seviyesi:** Orta
- **Çözüm:** $1.505 \times 10^{23}$ tane = $1.505 / 6.02 = 1/4 = 0.25 \ mol$.
$CH_4$ MA'sı = 16.
0.25 mol $CH_4$ kütlesi = $0.25 \times 16 = 4 \ gram$.
Aynı kütleye (4 grama) sahip Helyum (He) gazı:
He MA'sı = 4.
$4 / 4 = 1 \ mol \ He$ gazı eder.
1 mol gaz NŞA'da 22.4 Litre hacim kaplar. (C).

## Soru 8 (ID: KIM-TYT-K06-T19-S08)
- **Doğru Seçenek:** C
- **Kazanım:** Başlangıç katısından teorik Oksijeni bulup yüzde verime vurur.
- **Zorluk Seviyesi:** Zor
- **Çözüm:** Gerçekte çıkan Oksijen = 9.6 gram = $9.6 / 32 = 0.3 \ mol$.
Başlangıçtaki $KClO_3$ = 30 gram.
MA ($KClO_3$) = $39 + 35.5 + 48 = 122.5 \ g/mol$.
Başlangıç molü = $30 / 122.5 = 0.2449 \ mol$ (Küsüratlı).
Acaba "Yüzde kaçlık verimle" parçalandı?
Gerçekleşen: 0.3 mol $O_2$ çıkması için (Denklem: 2'den 3 çıkıyor),
$(0.3 \times 2) / 3 = 0.2 \ mol \ KClO_3$ harcanmış olmalıdır.
Elimizde 30 gram vardı, bunun $0.2 \ molü$ (Yani $0.2 \times 122.5 = 24.5$ gramı) harcanmış.
Verim Yüzdesi = (Harcanan / Başlangıç) $\times 100$
$(24.5 / 30) \times 100 = 2450 / 30 = 81.6...$ %81.6. (C).

## Soru 9 (ID: KIM-TYT-K06-T19-S09)
