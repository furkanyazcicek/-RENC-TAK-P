## Soru 1 (ID: KIM-TYT-K06-T10-S01)
- **Doğru Seçenek:** D
- **Kazanım:** Eşit kütledeki gazların mol sayılarını ve içerdikleri atom sayılarını orantılayarak kıyaslar.
- **Zorluk Seviyesi:** Orta/Zor
- **Çözüm:** Matematiksel kolaylık için kütleleri 64 gram (Eşit kütle) alalım.
$CH_4$'ün molü = $64 / 16 = 4 \ mol$.
$SO_2$'nin molü = $64 / 64 = 1 \ mol$.
İçlerindeki ATOM sayılarını hesaplayalım:
1 molekül $CH_4$'te 5 atom var. $4 \ mol \times 5 = 20 \ mol$ ATOM barındırır.
1 molekül $SO_2$'de 3 atom var. $1 \ mol \times 3 = 3 \ mol$ ATOM barındırır.
Sonuç: $CH_4$'ün atom sayısı (20), $SO_2$'nin atom sayısının (3) tam $\frac{20}{3}$ katıdır. (D).

## Soru 2 (ID: KIM-TYT-K06-T10-S02)
- **Doğru Seçenek:** B
- **Kazanım:** Yüzde bileşiminden katlı oranlar kanununu kullanarak yeni formül bulur.
- **Zorluk Seviyesi:** Orta/Zor
- **Çözüm:** Tablo Yapalım:
1. Bileşik ($XY_2$): %50 X, %50 Y (Kütleleri 50'ye 50).
2. Bileşik ($X_aY_b$): %40 X, %60 Y (Kütleleri 40'a 60).
Birinci bileşikte X'in Y'ye kütlece oranı = $50/50 = 1/1$. (Ve formül $XY_2$, yani 1 X atomuna 2 Y atomu düşüyor).
İkinci bileşikte X'in Y'ye kütlece oranı = $40/60 = 2/3$.
Birinci bileşiği 2 ile çarpıp genişletelim (Matematik için):
Oranı 2/2 yaparsak formül $X_2Y_4$ olur. (Burada 2 gram X'e 2 tane X atomu, 2 gram Y'ye 4 tane Y atomu düşüyor gibi düşünebiliriz. Oranlar üzerinden).
Daha pratik yol:
1. formülde X=1 iken kütlesi 50 ise, Y=2 iken kütlesi 50'dir (Yani 1 tane Y'nin kütlesi 25'tir).
2. bileşikte kütleler 40 X ve 60 Y.
X atom sayısı (a) = $40 / 50 = 0.8$.
Y atom sayısı (b) = $60 / 25 = 2.4$.
a ve b oranı: $0.8 / 2.4 = 1 / 3$'tür.
Yani kaba formül $XY_3$'tür. (B).

## Soru 3 (ID: KIM-TYT-K06-T10-S03)
- **Doğru Seçenek:** B
- **Kazanım:** "Eşit kütle" probleminde artan maddenin miktarını yüzde (%) olarak ifade eder.
- **Zorluk Seviyesi:** Orta/Zor
- **Çözüm:** $CO_2$'deki sabit oran $\frac{m_C}{m_O} = \frac{12}{32}$'dir (Yani 12 gram C'ye karşılık 32 gram Oksijen lazımdır).
"Eşit kütle" dediği için Büyük olana göre kaba madde koyalım. Kapta 32 gram C ve 32 gram O olsun (Başlangıç).
Oksijenin tamamı (32g) harcanır (Biter).
Karbonun ise sadece 12 gramı harcanır. Kapta $32 - 12 = 20 \ gram$ Karbon (C) ARTAR.
Soru: "Karbon, alınan kütlesinin yüzde kaçı arttı?"
Başlangıçta 32 gram almıştık, 20 gramı arttı.
Oran = $20 / 32 = 5 / 8$. Yüzde olarak = %62.5 Karbon (C) artar. (B).

## Soru 4 (ID: KIM-TYT-K06-T10-S04)
- **Doğru Seçenek:** C
- **Kazanım:** Hacimden molekül ağırlığına (MA) geçerek, kapalı formülü teşhis eder.
- **Zorluk Seviyesi:** Orta
- **Çözüm:** Önce gazın MA'sını (1 molünün kütlesini) bulalım.
1 mol olsaydı 22.4 Litre olacaktı. Bize 5.6 Litre verilmiş.
$n = 5.6 / 22.4 = 0.25 \ mol$ (Çeyrek mol).
0.25 molü = 11 gram ise,
1 molü = $11 \times 4 = 44 \ gram/mol$'dür. (MA = 44).
Şıklardaki gazların MA'larını hesaplayalım:
A) $CH_4 = 16$
B) $C_2H_6 = 30$
C) $C_3H_8 = (3 \times 12) + 8 = 36 + 8 = 44 \ g/mol$. (Eşleşti!).
D) $C_4H_{10} = 58$
Cevap $C_3H_8$ (Propan)'dır. (C).

## Soru 5 (ID: KIM-TYT-K06-T10-S05)
- **Doğru Seçenek:** B
- **Kazanım:** Parantezli kompleks bileşiklerde atom mol sayılarını katsayılarla dağıtarak hesaplar.
- **Zorluk Seviyesi:** Orta
- **Çözüm:** Bileşiğimiz: $0.2 \ mol \ Al_2(SO_4)_3$.
İçindeki atom sayılarını bulalım (1 molekülünde):
Al = 2 tane. S = 3 tane. O = $4 \times 3 = 12$ tane. Toplam = $2 + 3 + 12 = 17$ atom var.
I. $Al$ molü = $0.2 \times 2 = 0.4 \ mol$. (Doğru).
II. Toplam atom molü = $0.2 \times 17 = 3.4 \ mol$ atom. (Doğru).
III. Oksijen molü = $0.2 \times 12 = 2.4 \ mol$ O atomu vardır (Yani $2.4 \times N_A$ tanedir). Ancak şık $0.6 \times N_A$ demiş (Yanlış).
Doğru olanlar I ve II. (B).

## Soru 6 (ID: KIM-TYT-K06-T10-S06)
- **Doğru Seçenek:** B
- **Kazanım:** Bileşiğin 1 mol kütlesinden yola çıkarak bilinmeyen elementin atom kütlesini denklemlerle bulur.
- **Zorluk Seviyesi:** Orta
- **Çözüm:** 0.1 molü 16 gram ise,
1 molü (MA) = $16 \times 10 = 160 \ gram/mol$'dür.
Bileşik formülü $X_2O_3 = 160$ gram.
$2X + (3 \times 16) = 160$
$2X + 48 = 160$
$2X = 112 \Rightarrow X = 56 \ g/mol$ bulunur. (B).

## Soru 7 (ID: KIM-TYT-K06-T10-S07)
- **Doğru Seçenek:** C
- **Kazanım:** Tepkime sonrasındaki Toplam Gaz hacmini (Artan gaz + Ürün gaz) hesaplar.
- **Zorluk Seviyesi:** Orta/Zor
- **Çözüm:** Denklem: $1 N_2 + 3 H_2 \rightarrow 2 NH_3$
Başlangıç: $0.4 \ mol \ N_2$ ve $0.6 \ mol \ H_2$.
Sınırlayıcı Bileşeni Bulalım:
$N_2$ katı = 0.4 / 1 = 0.4 kat.
$H_2$ katı = 0.6 / 3 = 0.2 kat. (Küçük olan $H_2$, o hâlde SINIRLAYICI $H_2$'dir).
Tepkime 0.2 kata göre çalışır.
Harcanan $H_2$: Bitti (0 kaldı).
Harcanan $N_2$: $1 \times 0.2 = 0.2 \ mol$ harcandı. Kalan (Artan) $N_2$: $0.4 - 0.2 = 0.2 \ mol \ N_2$ ARTTI.
Oluşan $NH_3$: $2 \times 0.2 = 0.4 \ mol \ NH_3$ OLUŞTU.
Tepkime sonunda kapta; $0.2 \ mol$ artan $N_2$ + $0.4 \ mol$ oluşan $NH_3$ = TOPLAM $0.6 \ mol$ gaz bulunur. (C).

## Soru 8 (ID: KIM-TYT-K06-T10-S08)
- **Doğru Seçenek:** A
- **Kazanım:** Karışım gazlarının yanma tepkimelerinden çıkan ürünleri toplayarak, gaz karışımı denklemini çözer.
- **Zorluk Seviyesi:** Zor
- **Çözüm:** Karışımın hacmi (molü gibi düşünelim) toplam $20 \ L$.
$V_{CH_4} = x \ L$, $V_{C_3H_8} = y \ L$ olsun. $x + y = 20$.
Yanma tepkimelerinden çıkan $CO_2$ katsayılarına bakalım:
$CH_4$'ün katsayısı 1 Karbonlu $\rightarrow 1 \ CO_2$ çıkar (Yani x litre $CH_4$ yandığında x litre $CO_2$ çıkar).
$C_3H_8$'in katsayısı 3 Karbonlu $\rightarrow 3 \ CO_2$ çıkar (Yani y litre $C_3H_8$ yandığında $3y$ litre $CO_2$ çıkar).
Çıkan toplam $CO_2 = x + 3y = 44 \ Litre$.
Denklemlerimiz:
1) $x + y = 20$
2) $x + 3y = 44$
İkinci denklemden birinciyi çıkaralım: $2y = 24 \Rightarrow y = 12 \ Litre$ ($C_3H_8$).
$x + 12 = 20 \Rightarrow x = 8 \ Litre$ ($CH_4$).
Bize $CH_4$'ü (x'i) soruyor. Cevap 8 Litredir. (A).

## Soru 9 (ID: KIM-TYT-K06-T10-S09)
- **Doğru Seçenek:** D
- **Kazanım:** Tepkime ürünü üzerinden asıl harcanan saf reaktifi bulup, Saflık Yüzdesi (%) hesaplar.
- **Zorluk Seviyesi:** Orta/Zor
- **Çözüm:** Önce oluşan ürünü ($CO_2$) mole çevirelim:
2.24 Litre $CO_2 = 2.24 / 22.4 = 0.1 \ mol$.
Denkleme göre 1 mol $CaCO_3$'ten 1 mol $CO_2$ çıkar (Bire bir).
Demek ki 0.1 mol $CO_2$ çıktığına göre, reaksiyona giren (GERÇEK / SAF) $CaCO_3$ da $0.1 \ mol$'dür.
0.1 mol SAF $CaCO_3$'ün kütlesi = $0.1 \times 100 = 10 \ gramdır$.
Soruda bize cevher "20 gram alınmıştı" diyor.
20 gramlık kayanın sadece 10 gramı (YARISI) safmış, geri kalanı kirlilikmiş (kummuş).
Saflık Yüzdesi = $10 / 20 = 1/2 = \%50$. (D).
